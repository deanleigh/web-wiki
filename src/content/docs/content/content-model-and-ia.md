---
title: Content Model and IA
description: Structuring content so it is findable, reusable, and maintainable.
---

Information architecture and content model design belong together because structure drives both navigation and editorial consistency.

## Key decisions

- What content types are needed?
- Which fields are required for each type?
- Which taxonomy terms are controlled?
- How do users move between sections and related content?

## Done when

- Content types and required fields are documented.
- Navigation and taxonomy reflect real user journeys.
