---
title: Translation Workflow
description: Keeping translated content accurate, current, and aligned with the source.
---

Translation is not a one-off task. It is an ongoing workflow with the same governance needs as any other content stream.

## What to agree first

- Which content needs translating, and which can stay in the source language?
- Who provides translations, and how is quality reviewed?
- How are updates to the source language propagated to translations?
- Which terminology must be kept consistent across languages?

## Minimum baseline

- A defined process for requesting, delivering, and approving translations.
- A glossary or termbase for terms that must not vary.
- A way to flag stale translations when the source changes.
- Named owners for each language.

## Done when

- Translation process is documented and in active use.
- Stale or missing translations are visible and tracked.
